# Scratch repo usage (2026-10-07, v2)

How the author's **scratch** repo is set up and used as the file host for every Claude addon project: test builds, handover packs, saves, plans and notes. Attach this pack to a fresh Claude project alongside the WoW addon baseline and the addon-specific pack. It names no addon.

| File | What it holds |
| --- | --- |
| 01_PURPOSE.md | Why a scratch repo exists and what goes in it |
| 02_SETUP.md | Creating the repo and connecting it to Claude projects |
| 03_LAYOUT.md | The folder layout and naming |
| 04_USAGE.md | How to host each kind of file from a Claude session, and how to link it |
| 05_RULES.md | The rules for using scratch (the author adds more here) |
| templates/README.md | A starting index for the repo root |
| templates/handover-packs-README.md | A starting read-me for the handover folder |

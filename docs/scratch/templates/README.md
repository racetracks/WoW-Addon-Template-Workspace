# WoW-Addon-Template-Scratch

Private file host for the author's WoW addon project. Download any file as
`https://github.com/racetracks/WoW-Addon-Template-Scratch/raw/main/<path>`, read it in the browser with `/blob/main/<path>`.

| Folder | What is in it |
| --- | --- |
| latest/ | **Start here for a test build.** `<Addon>-latest.zip` is always the newest build; its README names the version |
| releases/ | Every test zip ever built, `<Addon>-<version>-<YYYY-MM-DD-hh-mm>.zip` |
| savedvariables/<version>/ | The author's real SavedVariables, by the version that wrote them |
| docs/ | Plans, feature designs and handover packs: `latest/<project>/` is current, `<project>/` and the zips are history |
| docs/handover-packs/ | **Start here for handovers.** Its README explains which pack to use |
| summary/ | The release notes of every production release |
